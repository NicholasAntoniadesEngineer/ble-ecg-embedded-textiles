# Introduction 
Code to instantiate Kymira Datasets from a variety of sources (e.g. clouddb, csv files and others).

## Installation

1. Clone the repository (or "Download zip file")
2. Install the module to the virtual environment of your project
   * For example: `pip install ./`

This will install all dependencies that are necessary for the module to work.
Further dependencies might be required in order to further develop the module.
In that case, please `pip install -r requirements.txt`.

## Documentation

Standard sphinx based documentation is available in `doc/`. To build the 
html index, do a `make html` from within the `doc/` directory and browse
the html documentation starting at `doc/build/html/index.html`.
