# Kymira EDICT Application

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

To run this project locally run these commands in the project directory

Install node modules
### `npm i`

Run locally
### `npm run dev`

This project was created using MUI v5 for components and styling and the BLoC pattern for project structure with RxJS for state management.
