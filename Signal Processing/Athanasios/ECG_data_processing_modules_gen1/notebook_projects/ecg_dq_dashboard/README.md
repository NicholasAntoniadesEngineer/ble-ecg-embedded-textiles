# ECG Data quality dashboard

A jupyter notebook to get a quick overview of a captured data stream's quality.

## Installation

1. Create a new virtual environment based on `requirements.txt`
2. Go to Kymira R&D git repository
   1. Download `read_ecg_data` as a zip, decompress to a temporary location, go to the top level 
      directory and run:
      * `pip install ./`
   2. Similarly for `ecg_data_processing_modules_gen1`, but make sure to install `modules/kymira_ecg`

## Use

Launch the jupyter notebook from this repository's `notebook_projects/ecg_hq_dashboard`
